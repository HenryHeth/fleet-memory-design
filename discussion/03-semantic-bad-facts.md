# Semantic memory · Stopping bad facts becoming "true"

**Memory type:** Semantic

## What we're seeing

In the one independent same-setup study, **every** memory engine sometimes repeated planted false claims. Engines that save automatically are the most exposed. A Hindsight user turned auto-save off after it polluted memory.

## Our current position

- Engines may only **propose** facts. They're tagged *inferred* and ranked below confirmed.
- A person confirms in a weekly 5-minute review before anything reaches the vault.
- Order of authority: confirmed fact > skill > original chat > recalled summary.

## Questions for you

1. How do you stop an inferred or wrong fact from hardening into truth?
2. Is a weekly human review sustainable, or does it get skipped? What would you automate?
3. Have you seen an engine "remember" something that was never said? How did you find it?

## How we'll test it

Inferred-fact tests: a hinted canary is stored as inferred, never promoted after a month, and confirmed wins on conflict.
