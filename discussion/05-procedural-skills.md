# Procedural memory · Skills that improve over time

**Memory type:** Procedural

## What we're seeing

No memory product reviewed handles procedural memory well. Hermes skills already do: versioned, patched after real wins and mistakes.

## Our current position

- Skills stay in Hermes (git); the index loads every session.
- G-Brain shares skills with other tools such as Claude Code.
- Skills are tested: the right skill loads unprompted, and a patched skill changes behaviour the next day.
