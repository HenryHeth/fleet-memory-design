# Across all types · One engine or two?

**Memory type:** All

## What we're seeing

We're vetting two designs. **Option A:** Obsidian + G-Brain + Hermes. **Option B:** the same, plus Mnemosyne on each agent for faster automatic recall. G-Brain is closest to our brief but untested by us; its Hermes pre-reply hookup is unverified.

## Our current position

- Run both on cloned test profiles with identical conversations for 30 days.
- A tie goes to Option A (simpler, one memory).
- Hindsight is the backup engine; Honcho if multi-party history becomes the gap.

## Questions for you

1. Has anyone run G-Brain with Hermes? Does it fill the pre-reply memory slot or only expose tools? What's the weekly upkeep?
2. Has anyone paired a fast per-agent memory with a shared one? Did they disagree?
3. Which engine would you pick for us, and why?
